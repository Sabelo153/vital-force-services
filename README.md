# Vital Force Services website

A multi-page website project by Sabelo Andile Biyela.

**Website:** https://vitalforceservices.co.za

## Included pages
Home, About, Services, Gallery, Contact, Privacy and Terms.

## Source
Static HTML and CSS, with the supplied logo, photographs and two videos. This repository preserves the website files supplied for the portfolio.

## Preview
Clone or download the repository, then open `index.html` in a browser. Keep the `media` folder alongside the HTML files.

This repository is a portfolio source copy. Publishing it does not change the existing website or its domain configuration.
